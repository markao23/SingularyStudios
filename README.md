# Singulary Studios Discord Bot

A **modular, production‑ready Discord bot** built with **discord.py**. It supports both classic prefix commands (e.g., `!ping`) and modern slash commands (e.g., `/ping`). The codebase follows a clean architecture, leveraging type‑hints, data‑validation, and a test suite to guarantee reliability.

---

## 📦 Project Overview

- **Language**: Python 3.12+  
- **Framework**: `discord.py` (v2.x)  
- **Architecture**: Extension‑based (each feature lives in its own cog)  
- **Configuration**: Managed via environment variables and validated with **pydantic**  
- **Testing**: `pytest` with `pytest‑asyncio`  
- **Static Analysis**: `ruff`, `mypy`

---

## 🛠️ Prerequisites

1. **Python 3.12** or newer installed on your system.
2. **Git** to clone the repository.
3. A **virtual environment** (recommended) – the project ships a `fish`‑friendly activation script.

## ⚙️ Setup & Installation

### 1. Clone the repository
```bash
git clone https://github.com/your‑username/SingularyStudios.git
cd SingularyStudios
```

### 2. Create a virtual environment
```fish
# For fish shell
python -m venv .venv
source .venv/bin/activate.fish
```
*For Bash/Zsh:* `source .venv/bin/activate`
*For PowerShell (Windows):* `.\.venv\Scripts\Activate.ps1`

### 3. Install dependencies (editable mode for development)
```bash
python -m pip install -e "[dev]"
# or, if you only need runtime deps:
python -m pip install -r requirements.txt
```

---

## 🔧 Configuration

1. Duplicate the example environment file:
```bash
cp .env.example .env
```
2. Open `.env` and fill in the required values:
   - `DISCORD_TOKEN` – **Bot token** from the Discord Developer Portal.
   - `DISCORD_GUILD_ID` *(optional)* – ID of a guild for immediate slash‑command sync. Omit for global registration.
3. **Never** commit `.env` or share your token.

---

## 🚀 Running the Bot

With the virtual environment activated:
```bash
python -m bot.main
```
The bot will:
- Log in using the provided token.
- Load all extensions declared in `EXTENSIONS`.
- Sync slash commands (guild‑specific if `DISCORD_GUILD_ID` is set).
- Emit a ready message with the bot's username and ID.

## 📜 Available Commands

| Command | Type | Description |
|---------|------|-------------|
| `/ping` | Slash | Responds with *Pong!* and latency.
| `!ping` | Prefix | Same as `/ping` but uses the classic prefix.
| `/uptime` | Slash | Displays a polished embed with the bot’s uptime.

Add new cogs under `src/bot/extensions/` and list them in `EXTENSIONS` inside `main.py`.

## 📦 Deployment Recommendations

- **Docker**: Create a lightweight container that mounts the source and injects the `.env` file as a secret.
- **Process Managers**: Use `systemd`, `supervisord`, or `pm2` (via `node`) to keep the bot alive and automatically restart on failure.
- **Monitoring**: Hook the bot’s logging into a centralized system (e.g., Loki, Papertrail) for easier troubleshooting.
